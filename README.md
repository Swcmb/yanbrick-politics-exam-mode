# 政砖沉浸式考试模式

把 [yanbrick.com/politics](https://yanbrick.com/politics) 的选择题练习改造成类似正式计算机考试的沉浸式答题界面：**一屏一题、键盘作答、答题卡、题面批注（草稿纸）、实时信息栏、最后一题交卷**。

以油猴脚本（Tampermonkey userscript）实现，答案、计时、交卷全部复用网站原生机制，不伪造任何数据。

## 功能

- **一屏一题**：只显示当前题，支持单选/多选。
- **题干格式与原生完全一致**：原生 `.pb-stem` 是 `white-space:pre-wrap` 的纯文本，题干里的换行就是分段/分条；这里同样按 `pre-wrap` + 15px/1.75 渲染，`①②③④` 各占一行、段首空格都原样保留，不会被压成一段。选项同理（纯文本 + 转义，`<`、`>` 按字面显示）。
- **长题干自动分栏**：单栏放不下、且题干占了大半屏时，自动切成一栏题干、一栏选项并排，选项不会被题干顶到屏幕外；短题干、窄屏不分栏。
- **顶栏信息**：实时计时（刷新不重置）、已作答 X/N、全站均分、题型·分值、当前题号。数字均来自页面真实数据，取不到显示占位。
- **键盘答题**：`A/B/C/D` 或 `1/2/3/4` 选择；单选按键即答即切下一题，多选可连续选择；任意题型都可按 `Enter` 或**空格**确认并切下一题；`←/→` 切题，`Esc` 关面板。
- **答题卡**：网格显示全部题号，未答/已答/当前三态，点击任意题号跳转并恢复答案。
- **题面批注（草稿纸）**：点顶栏「草稿纸」后，透明画布直接铺在题卡上，用鼠标/触屏/触控笔**在题目上就地划**（题干、选项、空白处都行），不再另开面板；画笔、橡皮、撤销、清空；**每道题笔迹独立**，切题即切换、切回来原样恢复；笔迹随题干一起滚动，长题干滚动也不错位；刷新后仍在。
- **交卷**：仅最后一题显示，确认面板展示已答/未答/用时，确认后驱动网站原生交卷流程，不重复提交、不自行宣告成功；等网站出成绩后自动卸载沉浸层、还原滚动，并把 `.pb-score` 滚到可见位置。判分 20 秒没出结果则恢复覆盖层并提示重试。
- **回看历次成绩**：在原生「历次成绩」里点「看这次」，脚本自动展开每道**错题**的解析（答对的题保持收起），并让出原生页面、不遮挡解析。
- **无需刷新即生效**：首次打开考试页、题卡晚于脚本渲染、浏览器从后台/bfcache 恢复、站点重渲染把覆盖层摘掉，都会自动补挂；原生直接出成绩（不经脚本交卷）或切到「作答 / 答案」时立即让位，不盖住结果页；换到新试卷后再自动恢复。持久关闭态不受影响。
- **兼容所有答题界面**：整卷 `/paper/*`、模拟/混合卷 `/mixed/*`、按科目练习 `/practice/*`、习题册 `/book/*`、`/bank/*`。非答题页自动不注入。
- **开关与退出**：顶栏「退出」会**持久关闭**沉浸模式并恢复原页面，之后不会自动弹出；答题页右下角保留一个「开启」入口，随时可重新进入。开关状态存在本地，刷新、切卷、重开浏览器都保持。
- **无多余滚动条**：挂载时锁住页面滚动，视口滚动条不再出现；长题干改为在题目卡内部滚动，滚动条收窄为细深色样式。
- **样式隔离**：全部 UI 在 Shadow DOM，不污染原站 CSS。动效克制且可关闭，遵循 `prefers-reduced-motion`。

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)（或 Violentmonkey）。
2. 打开脚本文件 [`dist/yanbrick-immersive-exam.user.js`](dist/yanbrick-immersive-exam.user.js)，CTRL+A 全选复制。
3. 在 Tampermonkey 面板「添加新脚本」中粘贴并保存。
4. 登录 yanbrick.com，进入任一答题页即自动启用。顶栏「退出」会持久关闭并在右下角留一个「开启」入口，不会自动再弹出。

> 仅匹配 `https://yanbrick.com/politics/*`，不影响其他站点。

## 快捷键

| 按键 | 操作 |
|---|---|
| `A`/`1`、`B`/`2`、`C`/`3`、`D`/`4` | 选择对应选项（按真实选项数动态映射） |
| `Enter` / `空格` | 确认并切下一题（单选、多选一致；未作答时等同于「下一题」） |
| `←` / `→` | 上一题 / 下一题 |
| `Esc` | 关闭答题卡 / 退出题面批注 |

输入框、批注落笔期间、输入法组合、长按时不触发答题快捷键；`Tab`、`Ctrl/Cmd+R`、`F12` 等一律放行。所有操作都有鼠标等价方式。

## 数据保存与恢复

| 数据 | 存储 | 说明 |
|---|---|---|
| 答案、计时起点 | 网站原生 `pol:paper-draft:{p\|m}:{paperId}` 的 `startedAt` / `picked` | 只经原生选项节点 click 写回，答案真值由网站持有；脚本不直接改答案字段 |
| 当前位置、提交状态、动效开关 | `pol:immersive-state:{paperId}` | 脚本自有键，与原生键职责分离 |
| 题面批注笔迹 | `pol:immersive-scratch:{paperId}:{题目id}` | 每题一个键，题目之间互不串写；坐标锚定题卡内容，随题干滚动 |
| 批注开关 | `pol:immersive-annot` | 记住上次是开还是关（默认关，避免误挡选项点击） |

所有键按 `paperId` 隔离，不同试卷互不干扰；24 小时原生草稿过期不偷偷续命，提示重开。保存失败明确提示，不谎称已保存。

## 题面批注实现

批注层是一张透明 `<canvas>`，绝对定位在题卡内容之上（层级高于文字、随题卡一起滚动），所以笔迹天然锚在题目上：滚到哪儿，标注就在哪儿。开关只切换 `pointer-events`——关闭时画布完全不拦点击，选项照常可点；打开时指针交给画布，直接在题干/选项上划。

`pointerdown/move/up/cancel` 统一鼠标、触摸、触控笔，按 `devicePixelRatio` 适配；画布高度取 `max(题卡可视高, 内容真实高度)`——**不能直接读 `scrollHeight`**，因为画布自己是 `absolute` 子元素，会被算进滚动区域导致「越量越高」的自反馈。题卡尺寸变化（换题、窗口缩放）由 `ResizeObserver` 重排，并按比例换算旧笔迹。橡皮用 `destination-out` 真擦除（画布是透明底，用背景色涂会在深色题卡上露馅）。笔画按题目 id 归档，撤销用操作栈。

## 运行与使用

- 浏览器：Chrome / Edge + Tampermonkey / Violentmonkey。
- 开发构建：`node build.js`，把 `src/` 下模块拼成单文件到 `dist/`。
- 单测：`node --test tests/core.test.js`。
- 集成测试：`D:/ProgramFiles/deeplearning/python.exe tests/integration_test.py`、`tests/edge_cases.py`（Playwright + 本地 fixture，无需登录态）。
- 真实站点端到端：`python tests/e2e_real.py`（首次会打开窗口，人工扫码登录一次；之后无头复用 `.e2e-browser-profile/`）。
